# 全内容语言切换

支持 `zh-CN`、`en`、`ja`。界面词条在 `src/ui-language.ts`，分类、科室、站点说明等用语在 `content/locales.json`。正文来自实际 Markdown 译文，不做词条替换，不调用运行时翻译服务。

同篇文章以 `translationKey` 关联；未填写时，删除 slug 的 `zh-cn/`、`en/`、`ja/` 路径段获得同组键。各版本保持自己的编号和地址。博客包含 67 组三语文章，共 201 篇；模板示例不进入博客。

用户批准核对后启用 74 篇既有英日草稿译文。发布、来源、关联与证据状态覆盖记录在 `migration/publication-overrides.json`；原始文档、快照和 `legacy.metadata` 不改。本轮按中文正文更新历史译文，重译 ResiCache 与 UltiCode 总览，补齐 Hindsight、OMP、知识库目录、日志、收件箱与大事记。历史事件、指标和检查结果仍是当时记录，不代表本轮重跑外部项目或服务。

切换保留文章组、查询参数和静态阅读模式，进入对应译文地址。`lang` 参数优先于已保存偏好。跨语言章节锚点会清除，因为译文标题的锚点可能不同。收藏按文章组映射；列表、搜索和五列选档每组仅显示所选语言。

静态文章也提供语言选择。中文 RSS 为 `/rss.xml`，英日 RSS 为 `/en/rss.xml`、`/ja/rss.xml`；下载使用对应正文与标签。代码、编号、来源路径、外部链接、作者姓名和品牌保留其身份。

维护译文时逐段对照中文正典，同时核对标题、摘要、日期、证据状态、来源、关联页面、示例和表格。站内文章链接指向对应语言，固定来源快照仍指向原地址。历史日志中的“当时未翻译／未发布”等事实照译，不能改写为本轮状态。

个人介绍等页面的内嵌 HTML 同样纳入文字、标题与链接检查；代码、路径和原始快照不按普通正文翻译。

`check:content` 使用现有 Markdown 解析器检查全量三语分组的标题段、代码块、表格行、外部来源和文章互链，以及来源、关联、状态、发布日期的一致性，并检测英文中的中文正文与缺少日文的版本。围栏和缩进代码按相同语义处理。结构检查不证明语义正确，也不能发现所有仅改措辞的过时结论；更新中文后仍须人工对照译文。

构建要求所有已发布文章组三语完整且同语唯一。`check:content` 检查全量分组、对应路由和锚点处理，并继续验证正文、离线、下载和稳定编号。浏览器验收覆盖主页、分类、搜索、收藏、设置、详情各标签、模型、静态阅读和刷新恢复；真实 iPhone 与视口模拟分别报告。

## 线上三语切换复核（2026-10-31）

线上验收分为两层：实际操作三语界面，以及全量读取公开文章页面检查语言、身份、搜索正文和站内链接。不能把 HTTP 页面检查写成逐篇浏览器点击，也不能把界面文案翻译写成原文修改。

| 界面 | 中文、英文、日文均实际执行的项目 |
| --- | --- |
| 搜索 | 全部结果、正文检索、分类筛选、最近发布排序、空结果与重置 |
| 设置 | 主面板、展开后的全部动效与画质选项、RSS 语言目标 |
| 文章详情 | 同篇切换、概述、研究记录、访问日志、标题与来源语言 |
| 目录 | 三语目录内容、对应章节锚点及跨语言切换后清除旧锚点 |
| 关联链接 | 实际点击同语文章，另全量检查站内文章目标与章节存在性 |

本次通用修复：设置底部整段署名复用本地化词条；中文搜索和详情的八项混排标签使用中文；动态文章编号前缀与静态页保持一致；日文“清晰度变化”使用“鮮明さの変化”。既有内容检查增加这些遗漏的回归断言。品牌、作者、编号值、代码和固定来源保持身份，原始文档与正文不改写。

下载功能不属于本次复核范围。未执行真实移动设备验证，不将桌面内置浏览器核验称为真实 iPhone 验证。

全量公开页面覆盖 67 组三语共 201 页、1479 处站内文章链接和 292 个章节锚点；201 份线上搜索正文与对应构建一致。未发现语言错配、缺失目标或失效锚点。页面内自带的 H1 和隐藏正文模板与文章标题分开检查，避免误把多个 H1 拼成标题。
