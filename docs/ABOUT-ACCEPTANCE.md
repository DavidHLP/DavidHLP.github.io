# About 验收清单

## 范围

模板提供独立 Astro 文档、资料字段、三语中性示例、双导航入口和打印样式。博客以同一内容集合读取现有三语介绍，不复制履历；原始快照与三维场景不改动。

## 执行顺序

- [ ] 模板与博客均通过 remote-dev 的 `build`、`check:content`、`check:viewport`。
- [ ] `/about/`、`/en/about/`、`/ja/about/` 可直达、刷新、分享；语言与正文、canonical、hreflang、站点地图一致。
- [ ] 交互导航和静态导航可进入；返回、前进、语言、主题偏好正常。
- [ ] 375、768、1440px × 亮/暗色截图审查；中英日长正文、姓名、链接无横向溢出或遮挡。
- [ ] 无头像、经历、教育、联系方式和 PDF 的最小配置不产生空卡片、标题或无效按钮。
- [ ] 正文自然滚动、选择、复制；Tab、锚点、焦点可见；减少动态效果下无必要动画。
- [ ] 禁用 JavaScript / WebGL 时仍可直接阅读与切换语言。
- [ ] 打印为白纸深色字，导航隐藏、正文完整、无固定舞台裁切；仅真实 public 文件显示下载。
- [ ] 博客旧 About 路由由真实页面接管；旧介绍文章及旧迁移地址仍可达，无重复路由或循环。
- [ ] 首页五列、文章、搜索、收藏、主题/语言、静态降级进行实际浏览器回归。
- [ ] 三方向独立审查完成并修复；证据记录环境、提交和操作范围，模拟视口不等同真实设备。

不涉及部署包装逻辑；如改变包装，追加 `build:cloudflare`。最终证据在交付记录中逐项说明通过、未验证或阻塞，勾选不得替代实际结果。
