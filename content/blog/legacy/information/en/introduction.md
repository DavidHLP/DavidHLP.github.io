## About

Java backend developer working on caching, distributed systems and maintainable engineering. Most of the work is making the fragile parts of a system explicit — cache consistency, task delivery, concurrency control — and writing the process down so it can be reviewed later.

## GitHub

Username `DavidHLP`, profile: <https://github.com/DavidHLP>.

Selected public projects:

- **ResiCache** — cache protection for Spring Cache + Redis: penetration, breakdown, avalanche and hot-key refresh.
- **UltiCode** — an open-source online judge with problem library, contests, sandboxed judging and an admin console.
- **RhineLabUI-Astro** — the archive-style theme behind this site, built with Astro and TypeScript.
- **codebase-memory-mcp** — a code knowledge-graph MCP server, with client integration contributions.
