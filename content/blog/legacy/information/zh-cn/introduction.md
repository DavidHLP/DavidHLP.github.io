## 关于我

Java 后端开发，关注缓存、分布式系统与工程可维护性。日常在做两件事：把系统里容易出错的地方（缓存一致性、任务投递、并发控制）想清楚，并把过程写成可复查的笔记。

## GitHub

用户名 `DavidHLP`，主页：<https://github.com/DavidHLP>。

主要公开项目：

- **ResiCache** — 面向 Spring Cache + Redis 的缓存防护，处理穿透、击穿、雪崩与热 Key 刷新。
- **UltiCode** — 开源的在线评测平台，包含题库、比赛、沙箱判题与后台管理。
- **RhineLabUI-Astro** — 本站使用的档案式界面主题，Astro + TypeScript 实现。
- **codebase-memory-mcp** — 代码知识图谱 MCP 服务，参与客户端接入相关贡献。
