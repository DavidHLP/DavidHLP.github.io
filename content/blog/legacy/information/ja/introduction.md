## プロフィール

Java バックエンド開発。キャッシュ、分散システム、保守しやすい設計に関心があります。システムで壊れやすい部分（キャッシュ整合性、タスク配信、並行制御）を明確にし、その過程を後から検証できる形で記録することを中心にしています。

## GitHub

ユーザー名 `DavidHLP`、プロフィール：<https://github.com/DavidHLP>。

主な公開プロジェクト：

- **ResiCache** — Spring Cache + Redis 向けのキャッシュ保護。穿透・ブレイクダウン・アバランチ・ホットキー更新を扱う。
- **UltiCode** — 問題ライブラリ、コンテスト、サンドボックス判定、管理画面を備えたオープンソースのオンラインジャッジ。
- **RhineLabUI-Astro** — 本サイトで使用しているアーカイブ風テーマ。Astro と TypeScript で実装。
- **codebase-memory-mcp** — コード知識グラフの MCP サーバー。クライアント連携に貢献。
