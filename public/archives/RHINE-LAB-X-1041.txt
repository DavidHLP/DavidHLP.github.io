テーマは外部リンクのオンライン申請インターフェースを**提供していません**。各ウェブマスターには自分のリンクリストを手動で管理することをお勧めします。

筆者は各ウェブマスターが外部リンクを真実で価値のある推薦として捉え、**本当に感謝し、定期的に読んでいる、または共有したい**サイトのみを収録することを奨励しています。

- [Astro](https://astro.build/) — コンテンツ駆動型ウェブサイト向けのモダンな Web フレームワーク。
- [Svelte](https://svelte.dev/) — より少ないコードで多くのことを行うコンパイル時フレームワーク。
- [TypeScript](https://www.typescriptlang.org/) — 型構文を備えた JavaScript のスーパーセット。
- [MDN Web Docs](https://developer.mozilla.org/) — Web プラットフォームの権威あるドキュメントと学習リソース。
- [GitHub](https://github.com) — 世界最大のオープンソース協業プラットフォーム。

交換や純粋なSEO目的で無作為に相互リンクを積み重ねるよりも、筆者は各リンクが**コンテンツの共鳴**と**価値の認同**の現れであり、個性と温かさに満ちたサイトネットワークを構築することを願っています。

外部リンクの表示を決定する場合は、それをサイトスタイルの延長として考え、コンテンツと一体化させ、信頼できる一部分にすることをお勧めします。
