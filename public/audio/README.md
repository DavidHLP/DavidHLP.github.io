# 音频来源与许可

`atmosphere.ogg`、`motif.ogg`、`pulse.ogg` 是本项目原创程序编配的同步循环配乐，没有外部录音、原片采样或人声，随仓库 LICENSE 授权。交互音效由 `src/audio.ts` 合成。

`src/typing-samples.ts` 的三个 38ms 输入短音来自《明日方舟》特别映像 [莱茵生命：访问]（BV1rr4y1b7sz）约 6.864–6.986 秒。`typing-source.json` 记录时间和处理参数。原音及衍生片段权利归原作者，不包含在原创配乐的 MIT 授权中；仅去直流、边缘淡变和统一增益，没有变调或变速。

历史配乐合成、短音提取和试听文件可从 Git 历史查看。
