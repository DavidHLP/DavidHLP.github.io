# Blog template migration

`DavidHLP.github.io` is the blog. [RhineLabUI-Astro](https://github.com/DavidHLP/RhineLabUI-Astro) is the generic upstream template. This repository retains its existing Git history and imports the upstream history through a merge; its local `upstream` remote points to the template. The existing GitHub repository is retained rather than deleted and recreated to change GitHub's fork-network metadata.

Original documents from blog revision `f49953fb0d4bd52a39bf81167b0c4b7dd7d78a64` remain in their original content paths and in the byte-for-byte `source/` snapshot. `manifest.json` records preserved documents, adapted articles, draft flags, copied assets and compatibility routes. Edit the template-compatible articles in `content/blog/legacy/`; the snapshot and original `src/content/` files remain unchanged as migration evidence.

Only the original public content collections are adapted for publication. Draft translations remain drafts. Immutable `src/content/raw/` evidence and repository maintenance documents are preserved without being turned into public blog articles. Evidence links point to the pinned original files. The template's fictional sample posts are not published in this blog.

The adapter preserves original frontmatter in `legacy.metadata`, dates, languages, tags, authorship and evidence status. MDX link cards and YAML chronology become ordinary Markdown; internal article links and public media use their new locations. Existing note URLs redirect to the corresponding template article, and old feed addresses return RSS XML. The five archive columns group backend engineering, operations, AI tools, project practice and site notes while retaining the template's model positions, materials and interaction.

The source documents retain their original licenses and attribution. `LICENSE` remains the blog's GPL license; the template's MIT license is included at `public/licenses/RhineLabUI-Astro-MIT.txt`. Original audio, fonts, models and public notices remain available. Individually licensed Novecento fonts are not committed.

Build and validate on `remote-dev` with `npm ci`, `npm run build`, `npm run check:content`, `npm run check:viewport`, `npm run kb:lint`, and `npm run test:kb`. GitHub Pages deployment remains in `.github/workflows/deploy.yml` and publishes only after validation. The import script is a one-time migration tool and must not overwrite subsequently edited articles. Mermaid diagrams render in both static reading mode and the interactive article panel; formula source remains preserved. External resources remain external. Editable wiki knowledge fields live in the adapted article frontmatter, and `kb:lint` validates those documents and their current index/log while checking immutable raw evidence in `src/content/raw/`.
